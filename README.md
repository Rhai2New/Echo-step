# 🎵 ECHO STEP: The Sonic Bridge

A high-altitude, memory-based rhythm platformer powered by Web Audio API and HTML5 Canvas. Listen closely to procedural melodies, memorize pitch-coded steps, and traverse the floating bridge across the chasm.

## 🎮 How to Play

1. **Listen:** At the start of each level, a unique, dynamically generated melody plays.
2. **Memorize:** Pay attention to the sequence of **Left Tones** (Cyan / C4) and **Right Tones** (Magenta / G4).
3. **Traverse:** Step onto the floating bridge tiles from memory. One wrong step will shatter the block into the abyss!
4. **Advance:** Complete all 5 increasingly complex levels to claim victory.

## ✨ Features

* **Procedural Sound Synthesizer:** Real-time dual-tone audio generated using the browser's native Web Audio API (no external audio files required).
* **Dynamically Generated Levels:** Every fresh playthrough creates unique melody patterns so no two runs are identical.
* **Particle Shatter Engine:** Real-time 2D canvas physics for block disintegration and footstep ripple rings.
* **Floating 3D Perspective CSS:** Dynamic spatial environment featuring a suspended, floating bridge perspective and high-altitude sky atmospheric gradients.
